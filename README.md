# Sawty — إيجنت صوتي بعامية مصرية

منصة SaaS تدي أصحاب البراندات (مطاعم، متاجر، أي خدمة) إيجنت صوتي بيرد على
تليفونات عملائهم بعامية مصرية طبيعية، مدرّب على بيانات كل براند (منيو
وأسعار، صفحات سوشيال ميديا، موقع)، وبياخد الأوردر ويبعته لصاحب البراند
أوتوماتيك.

## التشغيل محليًا

```bash
pnpm install
cp .env.example .env.local   # واملأ المفاتيح المطلوبة
pnpm dev
```

شوف [`SETUP.md`](./SETUP.md) لدليل كامل خطوة بخطوة (Twilio, OpenAI,
ElevenLabs, Resend, والنشر على Vercel) وشرح صريح للتكاليف والحدود الحالية.

## البنية

- `app/dashboard` — لوحة تحكم لإنشاء وإدارة البراندات ومتابعة الأوردرات.
- `app/api/brands`, `app/api/orders` — CRUD API للبراندات والأوردرات.
- `app/api/twilio/voice`, `app/api/twilio/recording` — الـ webhooks اللي
  بتشغّل المكالمة الصوتية (استقبال المكالمة → تسجيل → تحويل لنص → رد
  الذكاء الاصطناعي → توليد صوت → استمرار الحوار أو إنهاء المكالمة).
- `app/api/tts/[id]` — بيسيرف ملفات الصوت المولّدة لـ Twilio.
- `lib/ai.ts` — منطق الفهم والرد (OpenAI) والتحويل الصوتي (Whisper +
  ElevenLabs/OpenAI TTS)، وأداة `finalize_order` لاستخراج الطلب بشكل منظم.
- `lib/knowledge.ts` — بيجمع منيو + سوشيال ميديا + موقع كل براند في نص
  معرفي واحد يتحقن في الـ prompt بتاع الإيجنت.
- `lib/store.ts` — تخزين مؤقت في الذاكرة (راجع الحدود في `SETUP.md`).
